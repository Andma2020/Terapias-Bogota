# Terapia Web Page

Página web de terapia desplegada en GitHub Pages.

## 🌐 Ver en vivo

[Acceder a la página web](https://[TU-USUARIO].github.io/[NOMBRE-REPO]/)

## 🚀 Despliegue local

Para ejecutar localmente:

```bash
npm install
npm start
```

La página estará disponible en http://localhost:8080

## 📁 Estructura

- `terapia-1.0.0/` - Archivos del sitio web
  - `index.html` - Página principal
  - `css/` - Estilos
  - `js/` - Scripts
  - `img/` - Imágenes
  - `lib/` - Librerías externas

## 🛠️ Tecnologías

- HTML5
- CSS3 (Bootstrap)
- JavaScript
- jQuery
- Owl Carousel
- WOW.js
